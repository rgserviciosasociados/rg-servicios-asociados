# RG Servicios Asociados

Sitio web corporativo de RG Servicios Asociados, especializado en soluciones arquitectónicas, paneles móviles, mobiliario y remodelación de espacios corporativos.

## Desarrollo local

```bash
npm install
npm run dev
```

## Publicación

Cada cambio enviado a la rama `main` se compila y publica automáticamente mediante GitHub Pages.
